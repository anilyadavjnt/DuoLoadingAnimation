# DuoLoadingAnimation 🎨

A custom loading animation for iOS built with Swift and UIKit.

## ✨ Overview

DuoLoadingAnimation is an iOS project focused on creating a smooth, visually appealing loading experience. It demonstrates custom UI animation techniques and reusable components for iOS applications.

## 🚀 Features

- Custom loading animation
- Smooth UI transitions
- UIKit-based interface
- Reusable animation components
- Clean and maintainable Swift code

## 🛠️ Technologies

- Swift
- UIKit
- Xcode
- iOS SDK

## ⚙️ Requirements

- macOS
- Xcode
- iOS Simulator or a compatible iPhone

## 🔧 Installation

1. Clone this repository.
2. Open the `.xcodeproj` file in Xcode.
3. Select an iOS Simulator or connected device.
4. Build and run the project.

## 🎯 Learning Objectives

- Explore custom animations in UIKit
- Improve UI development skills
- Understand reusable iOS components
- Create engaging loading experiences
